# 首页与推荐更新

日期：2026-10-19，Asia/Shanghai。来源：本轮五条页面批注、首页逻辑请求，以及用户对“屏蔽色情、暴力等不适合未成年人观看的标题内容”的明确选择。

## 已完成

1. 首页回到 B 站当前热门列表，不再使用最近搜索词推荐；保留搜索历史供主动点击。
2. 热门接口读取 50 个候选，缓存最多 5 分钟并按北京时间日期分开；先按标题过滤、去重，再随机选 9 个。返回首页会重新抽取。
3. 标题词表共用于 API、前端和每日快照。覆盖色情/成人、血腥暴力、自残、赌博、毒品和惊悚等明确字眼；包括真实热门中出现的“成人网红”。可见尖括号文字、标签中断、零宽字符、标点和空格不会被当作绕过词表的方式。
4. 顶部新增小房子首页入口、北京时间实时日期/星期/时钟、指定的两行提示语，并将品牌图标改为 CSS/SVG 像素火柴人推门进入循环动画；系统减少动态效果时显示静态图。
5. 热门失败时诚实标记离线快照及更新时间；合格不足 9 个就显示实际数量，没有热门则为空，不补入被屏蔽内容或本地样片。

## 验证

- 34 项 Node 测试通过，覆盖原标题解析/流式转发以及本次筛选、抽样、日期边界、热门失败行为。
- 浏览器回归已验证：旧搜索历史不影响首页、9 个筛选结果、关键词搜索、小房子返回、播放器返回/浏览器后退、时钟更新、循环动画、离线筛选、897px 和 390px 布局。
- 真实热门接口返回 9 个唯一 B 站视频，标题均符合词表；连续请求顺序/内容重新随机。
- 当日快照已刷新，50 个真实候选中保留 49 个符合标题规则的条目，供页面每次随机抽取。
- 独立复核发现的可见尖括号文字漏筛问题已加回归测试并修复；641–800px 两行提示语改为块布局。浏览器脚本另补了 700px 断点检查，便于后续回归。

## 使用与限制

本机首页默认为 <http://localhost:3000/>；以终端实际显示的端口为准，开发验证曾使用 3010。如页面停留在旧状态，刷新即可。词表在 `public/recommendation-policy.js`，修改后需重启 Node 并刷新页面，快照也应重新生成。

“今日热门”指当前热门榜，可能包含以前发布的作品。筛选只根据标题关键词，可能误筛或漏筛，不分析视频画面和声音。不将“未成年人”三个字单独视作禁词。最初仅作用于首页推荐，同日后续已扩展到搜索，见下文。本文记录本地验证，不表示主分支或远端 API 已更新。
