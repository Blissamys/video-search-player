# 本地实时解析交付与验证

日期：2026-10-19，Asia/Shanghai。本页记录初期解析功能的验证；后续首页、搜索与“入门款”改动见 `homepage-update-2026-10-19.md`。完整版本当前包含 38 项 Node 测试。

## 如何打开

启动后访问终端显示的地址，默认为 <http://localhost:3000/player/>（开发验证曾使用 3010 端口）。粘贴 B 站链接或 BV/AV 编号，点击“解析 / 播放”，出现视频后点击播放按钮。

下次使用，在项目根目录双击 `启动本地测试.command`。脚本仅监听本机，自动打开默认浏览器；默认端口 3000，被占用时顺延，浏览器会打开实际端口。关闭终端窗口或按 Control+C 停止。需要 Node.js 18+；播放本身没有额外项目依赖。

可用于首次测试的输入：

```text
https://www.bilibili.com/video/BV1cTp66gEi7/
BV1cTp66gEi7
https://b23.tv/BV1cTp66gEi7
```

## 已知范围

本次实现适用于运行 Node 的这台电脑，通过 localhost / 127.0.0.1 访问。只播放上游允许匿名获取的普通公开视频**单段 MP4**；实际画质由 B 站决定。不支持登录态、付费、试看、番剧、直播、FLV、DASH 或多个文件分段；接口风控、网络或平台变化仍可能导致失败。自动逐帧依据实际呈现帧率估算，需要明确步长时手动选择已知帧率。

视频只在内存中流式传输，不保存视频文件。公网静态页、NAS、反向代理、Docker 网桥和 Serverless 不提供本轮新增的解析能力。现有官方嵌入、搜索和样片功能继续按原方式使用。
