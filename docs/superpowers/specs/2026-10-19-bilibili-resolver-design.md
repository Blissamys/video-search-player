# B 站本地实时解析设计

2026-10-19。来源：用户本轮需求及其对“实时解析视频流＋现有播放器控制”方案的确认。范围为本机测试。

## 行为

独立播放器接受 B 站 BV/AV 页面、BV/AV 编号、b23.tv 短链及分享文案中的链接。后端实时读取视频详情及当前 MP4 播放地址，选择分 P，并以流式转发接入原有 video 元素。保留倍速、音量、拖动、逐帧、帧率测量和本机文件功能。逐帧沿用浏览器按时间步进的实现，并非专业逐帧解码器。

首页保留现有搜索和嵌入播放，在视频面板新增“解析播放”入口。独立播放器显示标题、作者、实际返回画质、分 P、源站入口。浏览器仅保存原页面分享地址；不把临时媒体令牌写进分享链接。

## 接口和边界

- GET /api/resolve?url=...：仅本机调用，返回视频信息、分 P 列表、临时 playUrl、expiresAt。没有登录态时仅请求上游允许访问的普通公开视频。
- GET/HEAD /api/stream?token=...：仅本机调用，转发 MP4、Range、206 和 416；用户不能传入任意转发网址。令牌保存在有界内存表中，最多 30 分钟，并受上游地址过期时间约束。
- 详情及播放接口固定为 api.bilibili.com；短链逐跳验证，仅限 b23.tv 与明确支持的 B 站页面域名；媒体仅选择 bilivideo.com/bilivideo.cn 的标准 CDN，丢弃 P2P 节点和外部地址。
- 不将视频保存到磁盘。客户端切换视频或断开后终止上游连接。连接及读取超时有明确失败提示。
- 付费、登录限制、试看、无效分 P、风控及删除视频显示对应错误；用户可打开源站。播放失效最多自动重新解析一次，并恢复进度；也可手动重试。
- Node 本地页面优先调用同源服务；静态站仍保留原 API 配置。静态直开无法自行提供解析服务。

## 验收

使用 Node 原生测试覆盖输入和跳转验证、分 P、限制内容、CDN 筛选、令牌过期、Range 和备源、取消连接、本机访问边界。使用真实公开视频验证解析、媒体字节、浏览器解码、播放、拖动、倍速和逐帧；回归样片、本机文件和首页入口。公网不发布、不修改原始说明文件。
