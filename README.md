# 入门款 · 视频搜索播放器

一个本地运行的网页应用：输入关键词，自动合并多个来源搜索，并在网页内直接播放。

> 详细项目档案见 [docs/project-guide.md](docs/project-guide.md)。

## 本地实时解析 B 站链接（2026-10-19）

Mac 双击项目中的 **启动本地测试.command**，会启动本机服务并打开播放器。已安装 Node.js 18+ 即可运行，无需安装项目依赖。终端启动也可以：

```bash
HOST=127.0.0.1 node server.js
```

打开终端显示的地址（默认 `http://localhost:3000/player/`），粘贴完整 B 站视频链接、`BV1cTp66gEi7`、AV 编号或 b23.tv 短链，点击“解析 / 播放”，解析完成后点击播放按钮。分享文案中带链接也可以；多 P 视频会显示分 P 选择。

- 实时获取当前 MP4 流，支持声音、进度拖动、倍速、循环、逐帧与原有本机文件播放。
- 显示上游**实际返回画质**，不保证所有视频都有 720P。仅访问无需账号即可获取的普通公开视频；付费、登录限制和试看会明确提示。
- 视频通过本机流式转发，不写入磁盘；临时地址过期后最多自动重试一次，也可手动重新解析。
- 复制的播放页链接保存 B 站原页面地址，重新打开时重新解析。逐帧是浏览器按时间步进，自动帧率来自实际呈现帧数；精确控制可手动选择已知帧率。
- 首页选中 B 站视频后，点击“解析播放 · 倍速 / 逐帧”可进入此播放器；首页原有官方嵌入播放继续可用。
- **本次解析仅支持运行 Node 服务的这台电脑通过 localhost / 127.0.0.1 访问。** GitHub Pages、file://、局域网、反向代理及 Serverless 不提供此新增解析功能；已有搜索和嵌入功能仍按原部署方式工作。

后端新增 `GET /api/resolve?url=...` 和 `GET/HEAD /api/stream?token=...`。转发只接受解析器签发的临时令牌，不接受任意网址。纯静态文件服务也已补充 MP4/WebM Range 支持，修复本地样片拖动和逐帧定位。

验证：

```bash
npm test
# 可选浏览器测试需安装 playwright 和 Chrome，并先启动服务：
npm install --no-save playwright
npm run test:browser
npm run test:live
# 非默认端口：TEST_BASE=http://localhost:3010 npm run test:browser
```

`npm test` 不访问 B 站；`test:browser` 用受控接口响应检查交互，`test:live` 才使用真实视频验证播放。B 站网络、接口风控或可用格式变化仍会影响实时解析。

## 功能

- 多来源搜索：哔哩哔哩（真实接口，经本地服务代理）+ 本地样片库，自动合并
- 默认首页：始终从 B 站当前热门随机推荐 9 个，搜索历史不影响首页内容
- 搜索记录：本地保存最近 10 条，点击即可重搜，支持一键清空
- B 站视频通过官方嵌入播放器播放
- 样片库与直链视频使用内置播放器，支持：
  - 0.25x ~ 4x 倍速
  - 逐帧步进（可选 24 / 25 / 30 / 50 / 60 帧率，或按实测帧率自动）
  - 实测解码帧率显示
  - 循环、静音、音量、全屏
- 粘贴 B 站公开视频链接、mp4 / webm 直链即可播放（B 站解析需本机 Node 服务）

## 首页推荐与顶部（2026-10-19 更新）

- 点击小房子回到首页，或从播放器返回/浏览器后退，都会恢复热门推荐。搜索记录仍保留，可点击重搜。
- 热门池取 B 站当前热门列表的 50 个候选，缓存最长 5 分钟且按北京时间日期分开；每次返回重新随机抽 9 个，不限定视频必须当天发布。
- 推荐在抽样前按标题筛选、去重。词表位于 `public/recommendation-policy.js`，覆盖色情/成人、血腥暴力、自残、赌博、毒品和惊悚等明确用词，同时处理空格、零宽字符和标点分隔。“未成年人保护知识”等正常标题不会仅因提及未成年人而被拦截。
- API、浏览器回退和每日热门快照生成共用这份规则；合格视频不足 9 个时按实际数量显示，不用被屏蔽内容或样片补位。API 不可用时明确标注热门快照及更新时间。
- 顶部包含首页按钮、北京时间日期/星期/实时钟表、两行指定提示语，以及火柴人推门进入的循环像素动画。动画支持系统“减少动态效果”设置。
- 这是标题关键词筛选，可能误筛或漏筛，不代表已审核视频画面、声音或整体内容；可在词表中增减规则。最新规则同时作用于首页、实时搜索、加载更多和离线搜索；搜索保留原排序与结果数量，不限制为 9 条。

新增验证：`npm run test:home`（同样需要 Playwright、Chrome 和已运行的服务）。

## 运行

说明：直接打开文件时显示的是打包时的热门快照；启动本地服务后，热门与搜索均为实时数据。

### 方式一：直接打开（本地模式）

双击 `public/index.html` 即可在任何电脑上打开图形界面，无需安装任何东西：

- 内置 24 / 25 / 30 / 50 / 60fps 样片可搜索、可播放
- 倍速 / 逐帧 / 实测帧率等播放控制全部可用
- 支持粘贴视频直链播放
- 搜索记录可用（保存在浏览器本地）

注意：直接打开文件时无法调用 B 站搜索（浏览器安全限制）。把整个项目文件夹一起拷贝，样片和封面才能正常显示。

### 方式二：启动本地服务（完整模式）

要求 Node.js 18+，在项目根目录运行：

```bash
node server.js
```

打开 <http://localhost:3000>，额外获得 B 站真实搜索（经服务端代理）。如端口被占用，服务会自动尝试下一个端口。

刷新离线热门快照：

```bash
node scripts/update-hot.mjs
```

## 部署到公网

项目已内置 GitHub Pages 工作流，推送到 GitHub `master` 分支后会自动发布 `public/` 目录。

1. **GitHub Pages 静态公网**：访问 `https://shaochenyue.asia`。热门快照、样片播放、直链播放、搜索记录推荐可用；B 站实时搜索/热门需要 Node 后端。
2. **NAS / Windows / VPS 后端**：运行 `node server.js`，功能完整。B 站接口偶发风控时会自动回退本地样片并给出提示。

`shaochenyue.asia` 的 DNS 需要指向 GitHub Pages：

```text

A     @     185.199.111.153
CNAME www   <GitHub用户名>.github.io
```

指定端口：

```bash
PORT=8080 node server.js
```

## 用 NAS 运行实时搜索 API

NAS 需要支持 Docker。在项目根目录执行：

```bash
docker compose up -d --build
```

然后在 NAS 浏览器访问 `http://NAS的IP:3000/api/health`，看到：

```json
{"ok":true,"mode":"node"}
```

就说明实时 B 站搜索 API 已经可用。

推荐部署方式：

1. 主网页继续由 GitHub Pages 托管。
2. NAS 的反向代理把 `api.shaochenyue.asia` 转发到容器的 `3000` 端口，并配置 HTTPS 证书。
3. 阿里云 DNS 添加 `api A 记录`，指向你家宽带公网 IP。
4. 路由器把 80/443 端口转发到 NAS 反向代理。
5. 把 `public/api-config.js` 中的地址改为：

```js
window.VIDEO_API_BASE = 'https://api.shaochenyue.asia';
```

6. 提交并推送代码，GitHub Pages 会自动更新前端。

如果暂时不做 HTTPS，也可以在路由器转发 `3000` 端口，并使用 `http://api.shaochenyue.asia:3000`；但主页面使用 HTTPS 时，浏览器可能阻止这种 HTTP API 请求。

## 用 Windows 主机运行实时搜索 API

1. 安装 [Node.js LTS](https://nodejs.org/)。
2. 把项目文件夹复制到 Windows 主机。
3. 双击 `start-windows.bat`。
4. 看到 `http://localhost:3000` 启动信息后，在另一台设备访问 `http://Windows主机IP:3000/api/health` 测试。
5. Windows 防火墙需要允许 Node.js 的 3000 端口入站。
6. 如需公网访问，在路由器把外部端口转发到这台 Windows 主机的 `3000` 端口。

如果宽带没有公网 IP，或者运营商封了 80/443 端口，需要使用 NAS/路由器自带的内网穿透，或改用 VPS/云主机。

## 关于视频来源的说明

- **哔哩哔哩**：搜索经本地服务端代理 B 站公开接口。B 站可能触发风控（如 -412），页面会给出提示，稍后重试即可。
- **样片库**：本机生成的 24 / 25 / 30 / 50 / 60fps 测试片（`public/samples/`），离线可播，用于验证帧率测量与逐帧控制。

## 键盘快捷键（内置播放器）

- 空格：播放 / 暂停
- ← / →：后退 / 前进 5 秒
- `,` / `.`：上一帧 / 下一帧
- ↑ / ↓：加速 / 减速
- M：静音；L：循环；F：全屏
